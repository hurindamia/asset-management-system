Drop official software icons in this folder to replace the text badges on software.php.

Supported file types:
- .svg
- .png
- .webp
- .jpg
- .jpeg

Use these file names:
- autocad
- sketchup
- revit
- lumion
- 3ds-max
- rhino
- v-ray
- enscape
- twinmotion
- navisworks
- photoshop
- illustrator

Example:
- assets/software-icons/autocad.png
- assets/software-icons/sketchup.svg

The page will automatically use the real icon when the file exists.
